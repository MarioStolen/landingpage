Install in three steps.

CarGo is installed from an APK file, so Android will ask for a quick permission.

Download the APK

Tap Download APK. If your browser warns you about the file type, choose Keep.

Allow installs from this source

When prompted, open Settings and turn on Allow from this source for your browser.

Open the file and tap Install

Find the file in your notifications or Downloads folder, then tap Install.

Questions

Is CarGo free?

Yes. CarGo is free to download.

Do I need an account?

You need an account to book cars. Create one in the app when you’re ready to book.

Which Android versions work?

CarGo needs Android 8.0 or later.

Why does Android warn me during install?

CarGo is shared as an APK file instead of through an app store, so Android asks you to allow installs from your browser. You can turn that permission off again after installing.

Where is my data stored?

Your data stays on your device.
